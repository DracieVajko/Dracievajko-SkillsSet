# Katalóg

`skills.csv` a `skills.json` obsahujú všetky záznamy, úplný upstream repozitár, GitHub súbor, raw odkaz a stav overenia.

Stav `catalog-derived-not-http-validated` znamená odvodenie z predchádzajúceho katalógu, nie úspešný HTTP test. `catalog-id-known-branch-path-unverified` navyše označuje neoverenú konkrétnu vetvu OmniRoute. Verejný kandidát nie je dôkaz pôvodu lokálnej kópie.

Upstream implementácie, referencie a skripty NIE SÚ súčasťou ZIP. Aktívna inštalácia musí zachovať závislosti a licenčné podmienky upstreamu.

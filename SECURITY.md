# Security Policy

## Supported Versions

Security fixes are applied to the current `master` branch.

## Reporting a Vulnerability

Please do **not** open a public issue for a security vulnerability.

Use one of these channels:

1. GitHub private vulnerability reporting: `Security` tab → `Report a vulnerability`
2. If that is unavailable, contact the maintainer through GitHub: [@DracieVajko](https://github.com/DracieVajko)

Please include:
- affected file or component
- reproduction steps
- impact assessment
- suggested fix, if available

## Scope

This repository contains original documentation, prompts, rules, catalogs and
validation scripts. It does **not** bundle third-party skill implementations.
External skills are links only; report vulnerabilities in those projects to
their maintainers.

## Response

The maintainer will acknowledge reports as soon as practical and coordinate a
fix and disclosure. Please allow reasonable time before public disclosure.

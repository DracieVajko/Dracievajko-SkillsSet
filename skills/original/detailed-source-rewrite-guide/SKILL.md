# Detailed Source Rewrite Guide

Rewrite a source document (e.g., article, research paper) into a structured, step-by-step guide using AI.

## When to Use

- Rewriting a source document (article, research paper) into a structured, step-by-step guide.

## Procedure

1. **Fetch source document** — use web fetch to download the document (PDF or HTML).
2. **Extract key sections** — use AI to identify and summarize key points (methodology, results, etc.).
3. **Rewrite into guide** — restructure content into a step-by-step guide: Introduction, Step-by-Step Process, Key Considerations, References.
4. **Save as guide** — write the rewritten guide to a file.
5. **Verify output** — check completeness, accuracy and proper structure.

## Pitfalls

- Missing tools (web fetch, file write).
- Incorrect or inaccessible source URL.
- Poor extraction missing critical details.
- Factual errors compared to the original source.

## Verification

- All key points from the source are included.
- The guide is logically structured.
- No factual errors compared to the original source.
- The file is saved at the expected path.

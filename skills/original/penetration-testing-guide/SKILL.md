# Penetration Testing Guide

Penetration testing guide and methodology covering 5 phases: Recon, Scan, Gain Access, Escalate and Report.

## When to Use

- Planning or conducting security assessments, appsec penetration tests or security audits following standard methodology.

## Procedure

1. **Recon** — gather information and context about the target.
2. **Scan** — identify open ports, services and potential vulnerabilities.
3. **Gain Access** — exploit identified vulnerabilities safely (web apps, APIs, auth).
4. **Escalate** — test privilege escalation and lateral movement potential.
5. **Report** — document findings and provide clear fix recommendations.

## Pitfalls

- Skipping the reporting and remediation recommendation phase.
- Performing unauthorized scans or tests outside agreed scope.

## Verification

- All 5 phases are documented.
- Clear recommendations are provided for discovered vulnerabilities.

# GitHub Code Documentation

Create detailed descriptions and high-quality README.md files for scripts and programs intended for GitHub upload, push and commit. Also includes coding and "vibe-coding" rules to maximize efficiency and minimize errors.

## When to Use

- Creating detailed descriptions and high-quality README.md files for GitHub projects.

## Procedure

1. **Create README.md structure** using a standard template: Project Name, Description, Installation, Usage, Features, Configuration, Contributing, License.
2. **Generate detailed descriptions** for each section of the README.
3. **Include coding rules** — add coding and "vibe-coding" rules to ensure efficiency and minimize errors.
4. **Verify output** — check the generated README.md for completeness and correctness.

## Pitfalls

- Incorrect structure — README may not follow the correct template.
- Poor descriptions — descriptions may not be detailed enough.
- Missing rules — essential coding rules may be missing.

## Verification

- Check structure: README follows the correct template.
- Check descriptions: detailed and clear.
- Check rules: all necessary coding rules included.

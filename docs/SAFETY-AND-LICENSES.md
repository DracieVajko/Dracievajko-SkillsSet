# Bezpečnosť a licencie

- ZIP obsahuje novovytvorené pravidlá, inventáre a odkazy; nie upstream implementácie.
- Rešpektuj licenciu každého upstream projektu pred kopírovaním jeho obsahu.
- Dokumentové skills Anthropic môžu mať odlišné source-available podmienky.
- Balík zámerne nepridáva plošnú licenciu pre všetok uvedený externý obsah.
- Pred importom preskúmaj skill, skripty, prístupy a sieťové odosielanie dát.
- Bezpečnostné a hostiteľské pravidlá majú prednosť pred externým skillom.
- Zoznam URL nie je bezpečnostný audit ani test kompatibility.
- Pôvodný vstup s osobnými lokálnymi cestami nie je priložený k verejnému balíku.
